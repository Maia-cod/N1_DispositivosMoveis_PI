Ir direto para a tela

Como navegar

• Entrar → vai para a Agenda.
• Toque num card da lista → abre o Detalhe.
• Botão + (canto inferior direito) → Novo agendamento.
• Escolher data/hora → abre os seletores.
• Cancelar agendamento → diálogo de confirmação.
• Menu ⋮ na Agenda → Sair.

Fluxo principal

Login → Agenda → Novo agendamento → Agenda → Detalhe → Cancelar/Concluir.
